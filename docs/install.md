# Dterm 安装说明（v1.4.4）

**Dterm** 是 DSH 的手机外壳：独立的桌面图标、全屏、没有地址栏，直接连平板本机
Termux 里已经在跑的 DSH 服务（`127.0.0.1:3080`）。

它不装 DSH 本身——真正的 DSH 还是跑在 Termux/Ubuntu 里。所以：

- 装好后桌面会出现 **Dterm** 图标；
- 前提是 Termux 那边的 DSH 服务在运行（现在就是运行的；重启平板后没自动起来，
  见第 3 节）。

---

## 1. 安装 / 更新

1. 下载 [`release/Dterm-1.4.4.apk`](../release/Dterm-1.4.4.apk)，传到平板。
2. 用文件管理器打开它。
3. 之前装过 DSH 1.x 的：**直接覆盖安装**，不用卸载，登录状态保留
   （包名仍是 `dev.dsh.pad`，签名不变）。
4. 提示“未知来源/不允许安装”时允许文件管理器安装；Play Protect 拦截时点
   「更多信息 → 仍然安装」——本地自签名应用被提示是正常的。

## 2. 打开

点桌面 **Dterm** 图标。正常 1–2 秒直接进界面，**不需要登录**：应用会自己从本机
令牌桥取一次性令牌，换 30 天有效的 Cookie。

**长按桌面图标** 有三个快捷方式：

| 快捷方式 | 用途 |
| --- | --- |
| 重新加载 | 页面卡住、白屏、服务刚重启时重载 |
| 在浏览器打开 | 想看地址栏、用浏览器扩展时 |
| 打开 Termux | 服务没起来时去手动启动 |

万一只看到“需要登录一次”：浏览器打开 DSH，长按地址栏复制完整链接
（形如 `http://127.0.0.1:3080/?token=…`），回应用点“从剪贴板粘贴 → 进入”。
成功一次后 30 天不用再登录。

## 3. 提示“DSH 后台服务未运行”

**办法一（推荐）**：点 **“启动 DSH”**。应用会请 Termux 执行 `dsh-start`；如果
Termux 在后台不肯执行，5 秒后应用会切到 Termux 触发一次。Termux 里会**开一个终端
会话显示进度**：

```
▸ Dterm：正在启动 DSH…
（dsh-start 的输出）
▸ 已就绪，正在返回 Dterm…
```

跑完后 Termux 用 `am start` 把 Dterm 拉回前台，不用你手动切。应用最多等 2 分半。

用这个按钮前，Termux 里要放行一次：

```bash
grep -q '^allow-external-apps' ~/.termux/termux.properties 2>/dev/null \
  && sed -i 's/^allow-external-apps=.*/allow-external-apps=true/' ~/.termux/termux.properties \
  || echo 'allow-external-apps=true' >> ~/.termux/termux.properties
termux-reload-settings
```

第一次点按钮时系统会问是否允许 Dterm 在 Termux 中运行命令，选**允许**。

**如果 Termux 只在后台闪了一下、命令没执行**（等待超时的常见原因）：

1. 确认 Termux 里已放行：
   ```bash
   grep -n '^allow-external-apps' ~/.termux/termux.properties
   ```
   应输出 `allow-external-apps=true`；没有就按上面的命令加上并 `termux-reload-settings`。
2. 给 Termux 开「显示在其它应用上层」：
   `设置 → 应用 → Termux → 高级 → 显示在其它应用上层`（允许）。
   这是 Android 10+ 对后台启动终端会话的限制。
3. 从 1.4.1 起，应用发现 5 秒内没起来会**自动切到 Termux 触发一次**；
   从 1.4.3 起，触发命令里带上了 `am start`，**命令跑完由 Termux 把 Dterm 拉回前台**，
   不再依赖 Dterm 自己抢焦点。

离线页底部还有两个一键入口：

- **给 Termux 开「显示在其它应用上层」→ 后台直接启动**：开了之后连切 Termux 都不需要；
- **给 Dterm 开「显示在其它应用上层」→ 启动后自动回来**：开了之后切去 Termux 触发、服务起来会自动跳回 Dterm。

**办法二**：点 **“打开 Termux”**，手动执行：

```bash
dsh-runner
```

找不到命令就用完整路径：

```bash
bash ~/dsh-pad-deploy/scripts/dsh-runner
```

执行完切回 Dterm，它会自动重试。应用里的“复制命令”按钮会把 `dsh-runner`
复制到剪贴板，直接粘进 Termux 回车即可。

## 4. 能做什么

- 和浏览器里一样的 DSH 界面：对话、终端、文件、附件上传、下载、语音输入；
- 附件：输入框「＋」→「文件」，或直接点回形针，打开系统文件选择器；
- 下载：保存到平板 `Download/DSH/`；
- 返回键：先退网页历史，退到底再按一次退到后台；
- 外部链接、邮件、电话交给对应应用打开；
- 语音：第一次点麦克风会弹授权，允许后即可录音。

## 5. 常见问题

**白屏 / 一直转圈**
长按图标 →“重新加载”。仍不行就确认 Termux 服务在跑，再从最近任务划掉重开。

**提示“登录已过期”**
DSH 进程重启且 Cookie 也过期（30 天）。按第 2 节粘贴一次链接即可。

**语音按钮没反应**
第一次会弹麦克风授权，选“允许”。误点拒绝就去
`设置 → 应用 → Dterm → 权限 → 麦克风` 打开。

**桌面图标没变**
启动器缓存，等几秒或重启一次桌面。

**以后更新**
把新 APK 同步过来覆盖安装；若提示“签名不一致”，说明换了签名密钥，需要先卸载
（会清登录 Cookie，重装后按第 2 节登录一次）。
